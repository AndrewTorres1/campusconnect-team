# CampusConnect

## Project Overview

CampusConnect is a fictional campus event finder that helps students discover upcoming school events, activities, seminars, and programs happening around their campus.

## Features

- Browse upcoming campus events.
- Search for events by category.
- View event dates, times, and locations.
- Discover school activities and announcements.
- Keep students updated about campus happenings.

## How to Use

1. Open CampusConnect.
2. Browse the list of available campus events.
3. Search for an event using its name or category.
4. Select an event to view its details.
5. Check the event date, time, and location.
